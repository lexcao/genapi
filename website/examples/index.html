Examples

Each listing is a file from examples/github, copied verbatim from this repository.

examples/github/api/api.go

The interface you write. It embeds genapi.Interface and declares Contributors and CreateIssue.

examples/github/api/api.gen.go

The file the generator wrote. Its first line says it is generated and should not be edited.

examples/github/main.go

A program that calls genapi.New and then Contributors. On error it reads the response body from *genapi.Error.

Outside examples/

The optional Resty adapter's example is pkg/clients/resty/example/main.go. It is not part of the examples/ directory. pkg/clients/resty/example/main.go
