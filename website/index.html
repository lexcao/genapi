Declarative HTTP clients for Go — interface in, client out.

Write a Go interface, annotate each call, and run go generate. The generated file implements that interface, and your code calls it with ordinary Go types.

examples/github/api/api.go
Source 
package api

import (
	"context"

	"github.com/lexcao/genapi"
)

//go:generate go run ../../../cmd/genapi/main.go -file $GOFILE

// @BaseURL("https://api.github.com")
// @Header("Accept", "application/vnd.github.v3+json")
type GitHub interface {
	genapi.Interface

	// @GET("/repos/{owner}/{repo}/contributors")
	Contributors(ctx context.Context, owner string, repo string) ([]Contributor, error)

	// @POST("/repos/{owner}/{repo}/issues")
	CreateIssue(ctx context.Context, issue Issue, owner string, repo string) error
}

type Contributor struct {
	Login         string `json:"login"`
	Contributions int    `json:"contributions"`
}

type Issue struct {
	Title     string   `json:"title"`
	Body      string   `json:"body"`
	Assignees []string `json:"assignees"`
	Milestone int      `json:"milestone"`
	Labels    []string `json:"labels"`
}

Why genapi?

Less boilerplate
The interface is what you maintain. go generate writes the method bodies that call the HTTP client.
Type safety
Arguments and results are ordinary Go types, checked when the package compiles.
Interface and implementation
examples/github keeps the interface in api.go and the generated implementation in api.gen.go.
Runtime HTTP client
pkg/clients/resty/example/main.go passes resty.DefaultClient to genapi.WithHttpClient.

Annotation reference

  • Base configuration
  • HTTP methods
  • Parameters
  • Request body
  • Response
  • Headers

Base configuration

examples/github/api/api.go sets @BaseURL and @Header on the interface.

HTTP methods

examples/github uses @GET and @POST. website/api/todo.go also uses @PUT and @DELETE. The parser accepts those names, plus the aliases returned by RequestLine.alias.

Parameters

Path placeholders such as {owner} are arguments of the same name. @Query in the end-to-end test takes a key and a value. A value written as {name} is taken from the argument of that name.

Request body

CreateIssue takes an Issue value. The generated method sets Body to that value.

Response

Contributors returns ([]Contributor, error) and the generated method calls genapi.HandleResponse. CreateIssue returns error and the generated method calls genapi.HandleResponse0. A single non-error result uses genapi.MustHandleResponse, as written in the binder.

Headers

The GitHub interface sets Accept on every call. The httpbin end-to-end test also sets a method header. Both use @Header with a name and a value.
